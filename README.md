# Python Projects 

This repository contains Python projects I build while learning and practising Python programming. Each project helps me understand programming concepts and improve my problem-solving skills.

## Projects

### 1. Expense Tracker
A simple application to manage daily expenses.  
Users can add, view, and track their spending.  
Helps practise Python basics and data management.

### 2. Password Strength Checker
Checks the strength of a password based on different conditions.  
Identifies weak passwords and provides feedback.  
Helps practise strings, conditions, and validation.

### 3. Quiz Application
A command-line quiz where users answer multiple-choice questions.  
Displays scores based on correct answers.  
Helps practise loops, conditions, and dictionaries.

### 4. Contact Management System
Stores and manages contact information.  
Users can add, view, search, update, and delete contacts.  
Helps practise functions and data structures.

### 5. Library Management System
Manages books in a small library system.  
Users can add books and manage borrowing and returning.  
Helps practise OOP and object management.

### 6. Weather Application
A Python application that retrieves and displays weather information.  
Uses weather data to show current conditions.  
Helps practise APIs and JSON handling.

### 7. Expense Splitter
Helps split shared expenses among multiple people.  
Calculates individual contributions and settlement amounts.  
Helps practise dictionaries, functions, and file handling.

### 8. Student Grade Management System
Manages student details, marks, and grades.  
Calculates percentages, generates report cards, and displays class statistics.  
Helps practise OOP, JSON storage, and data processing.

### 9. Banking Management System
A simple banking application for managing accounts and transactions.  
Supports deposits, withdrawals, money transfers, and transaction history.  
Helps practise OOP, JSON persistence, and exception handling.

## Technologies Used

- Python 3
- Object-Oriented Programming
- JSON
- File Handling
- APIs
- Git and GitHub

## Purpose

The goal of this repository is to improve my Python programming skills by building practical projects, learning new concepts, and solving problems through hands-on practice.
